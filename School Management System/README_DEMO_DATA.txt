DEMO DATA SEEDER — The School of Thoughts, Sanghar
==================================================

Purpose
-------
This development-only patch fills the School Management System with a realistic Pakistan/Sindh-context DEMO dataset so all major screens, dashboards and reports can be reviewed together.

IMPORTANT
---------
- All student/staff names, CNIC/B-Form values, phone numbers, addresses and financial figures generated by this seeder are synthetic demo data.
- The only school identity intentionally used is the name/location supplied for the demo: The School of Thoughts, Sanghar, Sindh, Pakistan.
- No database migration is required because this patch does not change the schema.
- This patch also restores the previously discussed root redirect: app start -> Login when signed out, Dashboard when signed in.
- The seeder is idempotent. After a successful first run it writes a DEMO_DATA_SEEDED_V1 audit marker and will not duplicate the dataset on later app starts.
- Demo seeding runs only when DemoData:Enabled is true. This patch enables it in appsettings.Development.json only.

What is inserted
----------------
- School profile: The School of Thoughts, Sanghar, Sindh, Pakistan
- Current + previous academic sessions, terms, holidays and grading scheme
- Nursery/KG/Class 1–10, Sections A/B, Class 9–10 groups
- Pakistan-context subjects and class-subject mappings
- 120 fictional students + guardians + current/historical enrollments
- Current-month / recent student attendance
- Admission enquiries + pending applications
- Fee heads, class fee structures, concessions
- Six months of fee challans, receipts, partial payments and defaulters
- 22 fictional staff records
- Principal/Admin/Accountant/HR/Reception/Exam Controller + 10 Teacher demo user accounts
- Staff attendance + current/previous month payroll
- First Term exam with marks/results/grades/positions + upcoming assessment
- Current expenses, pending expense approval and other income
- Notices and recent audit activity

Installation
------------
1. Copy/extract the patch into the INNER project folder:
   D:\School Management System\School Management System\
2. Replace files in destination.
3. Make sure your database migration/update has already completed successfully.
4. Run the project in Development mode.
5. On the first successful start, wait a little longer than normal while the demo rows are inserted.
6. Login as principal and open Dashboard, Students, Attendance, Fees, Exams/Results, Staff, Payroll, Expenses, Reports and Notices.

No migration command is required for this patch.

To stop future demo seeding
---------------------------
After the first successful run, you may set:
  "DemoData": { "Enabled": false }
in appsettings.Development.json.

Even if left enabled, the DEMO_DATA_SEEDED_V1 marker prevents duplicate insertion.
